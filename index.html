🚀 Getting Started

Ruffle-Flash-PS5 is an emulator designed to run Flash content — the files that games and animations used to be saved as, called SWF files. For many years, Flash powered thousands of small games, cartoons, and interactive pages on the internet. When browsers stopped supporting it, that content became difficult or impossible to open.

This project solves that problem. It recreates the Flash player environment so you can open those old files again and enjoy them the way they were meant to look and behave. The software is built with safety and speed in mind, and it is developed openly so anyone can follow its progress.

You do not need to install a browser plugin, change any settings, or learn how to code. If you can download a file and double-click it, you can use Ruffle-Flash-PS5. Everything in this guide is written for a normal Windows user, so feel free to follow the steps in order and take your time.
